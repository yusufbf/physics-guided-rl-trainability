# Release status — V16 archived evidence

The V16 evidence archive was merged into the public repository via PR #2. GitHub release [v16-evidence-2026-10-04](https://github.com/yusufbf/physics-guided-rl-trainability/releases/tag/v16-evidence-2026-10-04) pins commit `4f2c5b8b72830e76df8cdfbe6d3280e46e527945`. Zenodo published the corresponding 131.6 MB software archive on 4 October 2026 as [DOI 10.5281/zenodo.23131258](https://doi.org/10.5281/zenodo.23131258). The Zenodo record shows the tagged GitHub source ZIP, open access, and the expected `raw_evidence/raw_mat/`, `raw_evidence/checkpoints/`, and `raw_evidence/scenario_bank/` directories.

The release contains 65 audited raw training-stat MAT files, 47 executed 100-scenario final-test MAT files, 47 selected Stage-10 pass checkpoints, a frozen final-test scenario bank, eight representative validation-bank classes, per-run mappings, and integrity manifests. Staged raw-result copies matched the SHA-256 values in audited ledgers. Git blob SHA-1 values matched local files at upload, and a recursive tree check found all 180 staged `raw_evidence/` files with no mismatches. Independent regeneration from archived sampling rules, saved configurations, and seeds matched all 21,172 recorded final/validation scenarios across all 112 raw-result files. A separate local staging copy passed both Python integrity verifiers. MATLAB R2024b generated Figures 2, 3, and 5–8 in PNG/TIF at 600 dpi and vector PDF/EPS; Figure 7 was visually checked for toolbar artifacts. Figures 1 and 4 are the manuscript's embedded publication artwork.

The historical SAC-A1-MS05 outcome remains infrastructure-censored and is not counted as a completed run. Historical per-run executed-source self-hashes were not recorded, so archived sources do not prove the exact bytes executed in every historical run. No end-to-end retraining replication is claimed. On 4 October 2026 the 131,631,615-byte ZIP was downloaded independently from Zenodo: MD5 `3760894d21d58de6fa0c8a2a73df74af` matched the record, all 398 ZIP entries passed CRC, and both bundled Python verifiers passed on the extracted archive (112 raw MAT files, 47 checkpoints, 21,172 regenerated scenarios). The authors confirmed acceptance of the CC BY 4.0 license displayed by Zenodo. MATLAB/toolbox compatibility and end-to-end retraining remain outside this transfer-integrity check. The tagged ZIP is a pre-DOI snapshot, so its README and release-status text retain prospective DOI language; the published Zenodo record and this live status file document the completed release.
